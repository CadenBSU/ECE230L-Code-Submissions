## Lab Questions

### In plain English describe the function and use of a multiplexer.
A multiplexer takes multiple inputs and assigns one of them to a single output
based on the value of a selector. It is useful when you have a set of inputs
and you only want to get the output of one of them.

### In plain English describe the function and use of a demultiplexer.
A demultiplexer takes one input and assigns it to one of multiple outputs
based on the value of a selector. It is useful when you have multiple
destinations that you want to send a singular input to.

### What other uses might these circuits have? (Think Shannon’s)
One example that this multiplexer and demultiplexer combination might be useful for
is a package delivery system, where the inputs are a set of packages, and the outputs
are different houses they might be delivered to. The selector inputs would define which
package needs to be delivered, and which house it needs to be delivered to.
